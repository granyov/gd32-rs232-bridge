# Lazarus SoftW RS232 — конфигурация 1.2.0-dev через SWD

> **Экспериментальная функциональность.** Это руководство относится к исходникам
> ветки разработки, **не** к опубликованным образам v1.1.0 в `firmware/`.
> Новая прошивка не прошла стендовые испытания; сначала сохраните штатную Flash.

## Принцип

Прошивка GD32F103C8T6 сохраняет прозрачный побайтовый мост без командного протокола.
Настройки **только считываются при старте** из двух последних страниц Flash:

| Назначение | Адрес | Размер |
|---|---|---|
| Приложение и таблица векторов | `0x08000000` – `0x0800F7FF` | 62 КиБ |
| Конфигурация A | `0x0800F800` | 1024 байта |
| Конфигурация B | `0x0800FC00` | 1024 байта |

Каждая запись — 32 байта с номером версии формата, счётчиком последовательности
и CRC32/ISO-HDLC. Остальная часть страницы заполнена `FF`. При загрузке выбирается
валидная запись с наиболее новым номером (с учётом переполнения). При повреждении
одного слота используется другой, при отсутствии двух корректных слотов —
настройки сборки (обычно **38400 / 38400, 8N1, без flow control**).

**Важное ограничение:** проверка CRC исключает случайное повреждение записи,
но не может определить, что пользователь выбрал неудобную скорость или включил
RTS/CTS без физически подключённого CTS. В таком случае восстановление **через
SWD**, а не автоматический откат из-за молчания порта.

## Поддерживаемые настройки

- Скорости двух сторон независимо: **1200–115200 бод**.
- Кадры: **8N1, 8N2, 8E1, 8E2, 8O1, 8O2, 7E1, 7E2, 7O1, 7O2**.
- Внешний RS-232: **без управления потоком** (по умолчанию) либо **RTS/CTS**.
- Внутренний UART RK3568: только TX/RX, **без аппаратного управления потоком**.
- Линия DTR постоянно активна, DSR не управляет передачей; XON/XOFF не работает.

У GD32 аппаратный USART использует 8-битное слово при 7E/7O и 9-битное при 8E/8O:
один бит занят чётностью. В 7-битном режиме мост очищает старший бит данных.
Две стороны с разной шириной кадра **не являются** 8-битным прозрачным мостом.
Быстрый отправитель и медленный получатель по-прежнему могут переполнить
буфер. При включении RTS/CTS очередь RS-232→хост подаёт RTS с гистерезисом
(запрет при 1536 байтах, разрешение при 512), а CTS останавливает передачу хост→RS-232.
Это программный механизм, его временные характеристики требуют испытаний.

## Безопасное изменение настроек

1. **Остановите приложения**, использующие соответствующий `/dev/ttyS*`;
   подключите исправный SWD-программатор к XP6 либо XP8 (см. BOARD_AND_FLASHING).
2. **Сохраните полную резервную копию Flash (64 КиБ)** и option bytes.
   Не выполняйте массовое стирание и автоматическое снятие защиты чтения.
3. Остановите MCU через OpenOCD и выгрузите обе страницы. Подберите конфигурацию
   OpenOCD к **фактическому** SWD-адаптеру и GD32, прежде чем выполнять команды.
   Пример команд внутри запущенного OpenOCD:

   ```text
   reset halt
   dump_image slot_a.bin 0x0800F800 1024
   dump_image slot_b.bin 0x0800FC00 1024
   ```

4. Посмотрите, какая страница активна:

   ```sh
   python3 tools/uvon_rs232_config.py show --slot-a slot_a.bin --slot-b slot_b.bin
   ```

5. Создайте новую конфигурацию: утилита выберет **неактивную** страницу и
   следующий номер записи. Не изменённые параметры наследуются от активной
   конфигурации; `--factory` начинает с заводских значений.

   ```sh
   python3 tools/uvon_rs232_config.py prepare \
     --slot-a slot_a.bin --slot-b slot_b.bin \
     --host-baud 38400 --host-frame 8N1 \
     --rs232-baud 9600 --rs232-frame 8N1 \
     --flow none --output rs232-config.bin
   ```

6. **Проверьте адрес из вывода утилиты.** Пишите и стирайте *только* названную
   страницу. Например, если выбран слот A:

   ```text
   flash write_image erase rs232-config.bin 0x0800F800 bin
   verify_image rs232-config.bin 0x0800F800 bin
   reset run
   ```

   Не используйте адрес примера, если утилита выдала `0x0800FC00`.
   Новый режим вступит в силу **после reset**. Хост Linux и внешний прибор
   необходимо перенастроить на согласованные параметры.

## Восстановление

Если обмен исчез: проверьте настройку Linux, соединения и CTS. Для возврата к
38400/38400 8N1 без flow control повторите SWD-чтение двух слотов и создайте
**новую запись** с `--factory`; запишите на неактивную страницу и выполните reset.
Работающий старый слот останется нетронутым до следующего изменения.

Если два слота повреждены, прошивка возьмёт заводские значения при старте.
При необходимости можно стереть **только обе страницы конфигурации**,
не удаляя приложение. Это крайний вариант: сначала сохраните дамп и
проверьте, что адреса относятся к установленному GD32F103C8T6.

При чтении через SWD глобальный счётчик `active_config_slot` равен
`0` (заводские), `1` (A), `2` (B). Доступность переменной зависит от ELF
с символами; проверенный опубликованный v1.1.0 её не содержит.

## Что не реализовано

Нет меню на хосте, настройки через UART, автоопределения скорости,
удалённой конфигурации, HDLC, RS-485, автоматической отмены неверных
с точки зрения оборудования параметров или изменяемых настроек без reset.
Бинарные файлы новой версии пока **не публикуются** в `firmware/`.
